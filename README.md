## About

Static website for Plasma Studios, built with Astro. It is available in Spanish and English (`/es/` and `/en/`); the root page redirects to the visitor's browser language and falls back to Spanish.

## Features

- Home page with a hero section and a team summary.
- Team page (`/nosotros`) with one card per member, role tags, a filter by role, and a profile page per member (`/nosotros/<id>`) written in Markdown.
- Work and Contact pages (currently placeholders).
- Light and dark theme: follows the system preference by default; the manual choice is saved in `localStorage`.
- Animated logo with Three.js, page transitions with GSAP and smooth scrolling with Lenis.
- Sitemap generated by `@astrojs/sitemap`.

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev        # http://localhost:4321
npm run astro check
npm run build
npm run preview    # serve the production build locally
```

`npm run build` runs `scripts/sync-team-roles.mjs` first (`prebuild`). It updates the `tags` field of `src/data/team.json` from the Discord server roles when `DISCORD_BOT_TOKEN` and `DISCORD_GUILD_ID` are set (a `.env` file works). Without them, or on any error, it is skipped and the build continues with the committed file.

## Team data

The team page reads `src/data/team.json` (22 members at the moment). Example entry:

```json
{
  "name": "Display name",
  "role": "",
  "discordAvatar": "/team/filename.png",
  "profileUrl": "https://discord.com/users/<id>",
  "id": "filename",
  "tags": ["Builder", "Web Developer"],
  "ceo": false
}
```

- Avatars go in `public/team/`.
- Each member has a profile in `src/content/team/<id>.md` (English) and `src/content/team/<id>.es.md` (Spanish).
- An empty array renders a "team under construction" placeholder.

## SEO and hosting

The site is published at [plasmastudios.vercel.app](https://plasmastudios.vercel.app).

Known pending item: `site` in `astro.config.mjs` and the `Sitemap` line in `public/robots.txt` still point to `http://169.58.226.205` (the old VPS). Update both to the real domain and rebuild so the sitemap and `robots.txt` use the correct URL.

`scripts/deploy.sh` is the original VPS deploy script: it builds the site and uploads `dist/` to `/var/www/plasmastudios` over SSH using the `plasma-vps` alias from `~/.ssh/config`. It stores no credentials.
